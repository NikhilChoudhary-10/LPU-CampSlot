# CampSlot Campus Room Availability System

A client-side web application built using **HTML5, CSS3, and JavaScript (localStorage)** for **CSE326: Internet Programming**.

## Features

- **Role-Based Portals:** Student, Faculty, and Administrator dashboards
- **Room Catalogue & Blocks:** Manage academic buildings, classrooms, labs, and seminar halls
- **Availability Search:** Filter rooms by date, time slot, and room type
- **Conflict Prevention:** Automatically prevents double-booking against scheduled classes and existing bookings
- **Approval Workflow & History:** Admin approval/rejection of booking requests with live status tracking
- **Timetable Management:** Weekly section and faculty schedules
